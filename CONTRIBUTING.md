# Contributing

1. Create a focused branch from `main`.
2. Use Conventional Commits such as `feat:`, `fix:`, `test:`, `docs:` and `ci:`.
3. Add or update tests for behavior changes.
4. Run `pnpm ci` before opening a pull request.
5. Include migration and rollback notes for database changes.

Keep pull requests small and do not commit credentials, `.env` files or database state.
