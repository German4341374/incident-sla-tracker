# Repository Guidelines

- Keep source code, comments, documentation, configuration, and commit messages in English.
- Never commit credentials, production incident data, personal data, or local environment files.
- Preserve strict TypeScript, DTO validation, consistent JSON errors, and Prisma migrations.
- Keep SLA calculations deterministic and add unit tests for every priority or deadline rule change.
- Add integration coverage for API behavior and optimistic or concurrent database updates.
- Run `pnpm run ci` and `pnpm audit` before publishing changes.
- Use Conventional Commits and document material architecture or security trade-offs.
